# 📊 Customer Sales Behavior Analysis

## 📌 Project Overview

**Customer Sales Behavior Analysis** is a data analytics project focused on understanding customer purchasing patterns and analyzing sales performance using historical sales data.

The project uses **Python, Pandas, NumPy, Matplotlib, and Seaborn** to clean, analyze, and visualize the data. The analysis helps identify customer behavior, top-performing products, sales trends, and valuable business insights.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales and revenue
- Understand customer purchasing behavior
- Identify high-value customers
- Find frequently purchased products
- Analyze product and category performance
- Identify monthly and seasonal sales trends
- Analyze customer purchase frequency
- Identify top-performing and low-performing products
- Generate actionable business insights
